O1 · 사이드 노트

의도

  • 첫 진입에서 "런닝 → 캐릭터 성장"이라는 컨셉을 한 문장으로 즉시 전달.
  • "운명 / 사주" 단어 미사용 — 사주는 100% 내부 시드, 가입 이후에도 사용자에게 노출하지 않는다는 원칙.
  • CTA 단일화. 소셜 로그인 종류 선택은 다음 화면(O2)으로 분리해 첫 화면 인지 부담을 낮춤.
  • 캐릭터 일러스트는 와이어 단계에서 placeholder. 실제 단계에서는 ART_STYLE_GUIDE 기반 알/일러스트 사용.

대안

  • 다단계 캐러셀(스와이프 3장)로 컨셉 소개 — 첫 진입 이탈률·전환 지연 우려로 단일 화면 선택.
  • 로그인 버튼 3종을 첫 화면에 바로 노출 — 첫 화면 정보량 과다로 보류.
  • 캐릭터 대신 런닝 일러스트 — 핵심이 "캐릭터 성장"이라 캐릭터 우선.

미정

  • 캐릭터 일러스트 톤 — 실루엣 한 컷 vs 디테일 있는 알 일러스트.
  • 메인 카피 워딩 — "달리면 자라는 나의 캐릭터" 외 대안 풀 필요.
  • 로고 위치·크기 — 상단 작게 vs 중앙 큼직하게.
  • "이미 계정 있어요" 별도 진입선 필요한지 — 소셜 로그인이 가입·로그인 겸용이라 일단 미포함.
  • PWA 설치 안내 배너 위치 (이 화면 vs 메인 진입 후).
