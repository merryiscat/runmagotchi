O1 · 사이드 노트

의도

  • 풀스크린 애니메이션으로 "달리기 → 캐릭터 성장" 컨셉을 감성적으로 전달. 텍스트 설명보다 영상이 효과적.
  • 영상 끝나면 자동 페이드아웃으로 소셜 로그인 노출 — 별도 화면 전환 없이 자연스러운 흐름.
  • 로그인 화면은 로고 + 버튼만. 카피·캐릭터 이미지 제거 — 영상이 컨셉 전달을 담당하므로 로그인은 미니멀하게.
  • "건너뛰기" 버튼으로 재방문 사용자의 불편 방지.
  • 소셜 로그인 3종(Google/Kakao/Naver) — Apple 제외(생년월일 제공 불가).
  • 로고는 별도 제작 예정. 현재 텍스트 placeholder.

대안

  • 영상 없이 정적 일러스트 + 카피 — 컨셉 전달력 약하지만 로딩 빠름. 영상 제작 실패 시 fallback.
  • 영상 자동 재생 대신 재생 버튼 클릭 방식 — 사용자 의지 개입이지만 전환율 하락 우려.
  • 영상 종료 후 별도 화면으로 전환(라우팅) — 페이드 전환이 더 몰입감 있어서 보류.
  • 소셜 로그인을 영상 위에 오버레이 — 영상 집중 방해 우려로 분리.

미정

  • 영상 길이 — 5초? 10초? 15초? 너무 길면 이탈, 너무 짧으면 전달 부족.
  • 영상 반복 재생 여부 — 1회 후 자동 전환 vs 루프 재생 + 수동 CTA.
  • 재방문 시 영상 스킵 — 쿠키/로컬스토리지로 자동 스킵할지, 매번 보여줄지.
  • 영상 로딩 실패 시 — 정적 이미지 fallback? 바로 로그인 화면?
  • 캐릭터 placeholder 이미지 — 영상 마지막 프레임의 캐릭터와 일치시킬지.
  • 모바일에서 영상 자동 재생 제한 (iOS Safari muted 필수) 대응.
  • 약관·개인정보 처리방침 링크 연결 대상 (아직 문서 미작성).
