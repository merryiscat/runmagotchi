의도

  • 모든 진화 시점 통합. M1 stage·panel 그대로 유지하고 stage 위에서만 연출 변화. panel은 부화·진화 중에도 활성 — 사용자 동선 막지 않음.
  • 부화 패턴: ① 알 균열 → ② 부화 중 → ③ 유아 등장 + 이름 짓기 (3단계). 진화 패턴: ① 빛 폭발 변신 → ② 새 단계 등장 (2단계). 진화는 시각 임팩트가 한 번에 일어나는 디지몬 진화 스타일이라 중간 분리 불필요.
  • 모드 A 부화 (1회): 알 균열 → 균열 진행 → 유아 등장 + 이름 짓기 팝업. 팝업은 성별 표시 + 이름 입력만 — 부화 순간 시각 집중을 위해 다른 정보는 모두 제외.
  • 알·균열 시퀀스 = 고정 이미지 + 사용자 color_palette 적용. 모든 사용자에게 동일 형태, O2에서 선택한 색상만 다름. AI 이미지 생성은 ② 동안 백그라운드에서 유아 캐릭터 1장만 — 알 단계는 생성 비용 0.
  • 모드 B 일반 진화 (4회: 10/20/30/40 만점): 빛 폭발 + 실루엣 변신 (디지몬 진화 스타일 참조) → 새 단계 등장. 팝업 없음 — 이름·DNA는 이미 있고, stage__footer의 단계 토큰만 갱신.
  • 모드 B의 시각 모티프(디지몬식 빛 폭발 변신)는 부화의 균열과 다르지만 panel 정합은 같음.
  • 공개 필드는 이름·성별 2개뿐. 나머지(archetype·fantasy_modifier·signature_marks 등)는 내부 시드 — 화면 노출 금지.
  • 이탈·취소 차단. 중간 이탈 시 M1 재진입에서 다시 자동 발동.

대안

  • 부화·진화 별도 파일 (E1·E2 분리) — 시각 패턴 유사해 한 파일 통합이 더 깔끔 (현재 채택).
  • 모드 B 진화 시 단계별 별도 화면 (E1·E2·E3·E4) — 시각 모티프가 단계별로 크게 다르면 분리. 현재는 토큰화로 한 파일에 포괄.
  • 이름 변경 가능 — 정체성 보존 원칙과 충돌.
  • 이름 짓기를 stage 인라인 폼으로 — 캐릭터 가림, 팝업이 자연스러움.
  • 풀스크린 모달로 전환 — M1 컨텍스트 유지 원칙과 충돌.

미정

  • 모드 B 시각 모티프 세부 — 단계별로 다른가? 통일된 디지몬식 빛 폭발인가? (단계 갈수록 빛 강도 증가?)
  • 알 균열 시퀀스 단계 수 — 2단계? 3단계? 4단계? 전환 타이밍.
  • 빛 폭발 변신(모드 B) 모션 디테일 — CSS 키프레임 / Lottie / SVG 마스크. 디지몬 진화 참조 정도 (빛 폭발 강도·실루엣 깜빡임 횟수·색감).
  • ① → ② → ③ 전환 시각 길이.
  • 이미지 생성 실패 시 → E2 생성 실패 화면 전이 (예정) vs 인라인 재시도.
  • P1 프로필에 노출할 캐릭터 정보 범위 — 이름·성별 외 추가 공개 항목 있는지.
  • 7초 초과 시 — 백그라운드 전환 후 푸시 vs 계속 대기.
  • 모드 B에서 새 단계 등장 시 마이크로 임팩트(스크롤바·진동·사운드 등) 여부.
  • 이름 중복 검사 — 글로벌 / 본인 컬렉션 / 미검사.
  • signature_marks 표시 위치 — DNA 카드 항목 vs 캐릭터 위 핀.
  • 모드 B 후 칭호 자동 부여 여부 (단계 진입 칭호?).
  • Lv.50 완성(명예의 전당 + 새 알 가챠) 화면은 별도 ID로 분리 예정 (E2 또는 새 prefix).
