의도

  • 시안 B 채택: 좌 스테이지 / 우 패널. 캐릭터가 항상 시야에.
  • 알·캐릭터 상태 구분 없음 — M1은 단일 레이아웃. 알은 캐릭터의 1단계(시작 단계)로 통합 표현. stage에 현재 단계 외형만 바뀌어 표시된다.
  • 스테이지: 캐릭터가 자유 이동 (Sprite+JS). 단계 외형만 진화 시 변함.
  • 부화 조건: 누적 10km 달성. 진행도 비공개 — 어느 순간 깨어나는 서프라이즈. 달성 시 stage 위에서 알 깨지는 연출 → 캐릭터 등장 → 이름 짓기 팝업. panel(스탯·업로드·기록)은 그동안에도 활성 유지 — 부화가 사용자 동선을 막지 않는다.
  • stage 풋터: 이름·레벨·단계. 알 단계는 이름이 빈 토큰, 부화 후 채워짐.
  • 스탯 기간 드롭다운: 이번 달/지난 달/3개월/올해/전체/기간 설정. 기간 설정 시 date picker 팝업.
  • 최근 기록 3건 + "전체 보기" → M2(전체 기록) 화면으로.
  • GNB: 업로드/칭호/프로필 3개.

대안

  • 풀스크린 스테이지 + 오버레이 (시안 C) — 게임감 강하지만 정보 접근성 낮음.
  • 바텀 드로어 (시안 E) — 모바일에서는 좋지만 웹에서 어색.
  • 스탯 기간을 탭 방식 — 드롭다운이 공간 절약.

미정

  • 기간 설정 date picker UI — 캘린더? 시작일-종료일 입력?
  • 스테이지 배경 — 레벨/진화 단계에 따라 변하는지.
  • 캐릭터 클릭 시 인터랙션 (터치 반응, 대사 등).
  • 모바일에서 스테이지/패널 스택 시 스테이지 높이.
  • 알 상태 미세 모션 디테일 — CSS만? Lottie?
  • EXP 획득 내역 보기 진입점.
