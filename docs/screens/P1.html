P1 · 사이드 노트

의도

  • 실험 스타일 채택 — 좌측에 캐릭터+토글 고정, 우측에 정보 스크롤. 캐릭터를 항상 보면서 정보 탐색.
  • GNB(frame--web) + 프로필 탭 활성. M1/E1/E2/E4와 동일 패턴.
  • 사이드바: 캐릭터 이미지 + 이름 + 성별 + 화면 표시 토글. 레벨·단계·EXP 비공개. 성장 중 캐릭터는 항상 ON(토글 불가). 완성 캐릭터만 넣고 뺄 수 있음.
  • 정보 영역: 런닝 통계(평생 누적) + 칭호(획득 기록만) + 설정 링크.
  • 모바일(768px 미만)에서는 세로 스택 — 사이드바가 상단, 정보가 하단.
  • 알 상태: 동일 레이아웃. 사이드바의 캐릭터 이미지=알, 이름/성별=???. 화면 표시 토글·칭호는 비어있음.
  • 공개 필드(이름·성별)만 노출.

대안 (4스타일 비교 결과)

  • 보편(세로 단일 컬럼) — 무난하나 캐릭터가 스크롤 밖으로 사라짐.
  • 미니(토글만) — 정보 부족.
  • 오버(스탯 그리드+타임라인) — 과잉.

미정

  • stage 동시 표시 상한.
  • 캐릭터 탭 시 상세 보기 여부.
  • 설정 화면 범위 (로그아웃·탈퇴·알림).
