의도

  • 알 3개는 형태 동일, 색상만 다름. 사주 기반으로 추천된 3가지 색상이 각 알에 적용.
  • 이름·타입·상세 정보 일절 없음. 색상만 보고 직감으로 선택 — 기대감·궁금증 유발.
  • 선택한 색상이 캐릭터의 color_palette 기본 색이 된다.
  • 알·균열 시퀀스는 모두 고정 이미지. 여기서 선택한 색상이 알 자체뿐 아니라 부화 시 균열 1·2·3 단계 이미지에도 그대로 적용됨 (E1 모드 A). AI 이미지 생성은 알·균열에 없고 유아 단계부터 시작.
  • 이름은 부화 후 사용자가 직접 짓는다 (E1 모드 A ③).

대안

  • 색상+형태 모두 다르게 — 형태 통일이 선택 부담 줄이고 색감 집중 유도.
  • 알 1개 자동 확정 — 선택권이 있어야 애착.

미정

  • 사주→색상 매핑 룰 — 오행 기반? 일주 기반? 3색 추출 로직 설계 필요.
  • 선택 확정 전 되돌리기 가능 여부.
  • 선택 시 알이 살짝 반응하는 마이크로 인터랙션.
  • 모바일에서 세로 스택 vs 가로 스크롤.
