# Runmagotchi 화면 기획 — 도메인 규칙

`screen-plan` 스킬이 작성 전 읽는 프로젝트 고유 규칙. 스킬은 시각·구조·협업만 책임지고, 아래 도메인 어휘는 이 문서를 따른다.

> 변경 시 같은 폴더의 모든 화면 HTML과 정합 점검 필요.

---

## 1. 영역 prefix

| Prefix | 영역 | 비고 |
|--------|------|------|
| O | 온보딩 (Onboarding) | 랜딩·소셜 로그인·알 선택 |
| M | 메인 / 대시보드 (Main) | 로그인 후 기본 화면 |
| U | 업로드 (Upload) | 스크린샷 업로드 → VLM 파싱 → 확정 |
| E | 진화 (Evolution) | 부화·진화 연출, 생성 실패 |
| P | 프로필 (Profile) | 사용자·캐릭터 정보 |
| B | ~~삭제~~ | 칭호는 P1 프로필에 통합 |

새 영역 필요 시 한 글자 prefix 추가하고 사용자에게 확인.

## 2. 금지어 (사주 비공개 원칙)

와이어 카피·라벨·토큰에 절대 등장 금지:

- **운명**
- **사주**
- "운명의 ~", "당신의 사주는 ~" 등 변형 일체

S2(알 선택) 등 사주 기반 화면에서도 사주 단어 자체를 카피에 노출하지 않는다.

## 3. 비공개 필드 (내부 시드)

사용자 노출 금지. 와이어 어디에도 표시·언급 금지:

- `element_base` (사주 오행 기준)
- `element_balance` (오행 균형 비율)
- `temperament` (기질)
- `archetype` (아키타입)
- `fantasy_modifier` (속성)
- `signature_marks` (표식)
- `color_palette` (색상)
- `lore_one_liner` (한 줄 소개)
- `일주` / `월주` / `년주` 등 사주 용어 일체
- `십신` 관련 모든 표기

## 4. 노출 가능 필드

사용자에게 보여도 되는 화이트리스트. 이것만 화면에 노출:

| 필드 | 라벨 | 토큰 |
|------|------|------|
| `name` | 이름 | `{캐릭터 이름}` |
| `gender` | 성별 | `수컷` / `암컷` |

그 외 모든 필드(`archetype`, `fantasy_modifier`, `signature_marks`, `color_palette`, `lore_one_liner` 포함)는 내부 시드. 화면에 노출 금지.

## 5. 카피 보조 규칙

- 짧고 건조하게. 2~3단어 이내. (예: "확정", "다시 선택", "부화 중...")
- 반말도 존댓말도 아닌 **명사·라벨 중심** ("업로드", "결과 확인").
- 친절체 금지 ("~해 주세요", "~하시면 됩니다", "당신만의 ~").
- 감탄사·이모지·느낌표 금지.
- **내부 구현 단어 노출 금지**: 사용자 카피·라벨에 "이미지 생성", "AI 생성", "백그라운드 생성", "VLM 파싱", "GPT 호출" 등 기술 디테일을 적지 않는다. 사용자에게는 "부화 중...", "진화 중...", "분석 중..." 같은 결과 표현만 사용. 대기 시간은 "최대 7초" 식으로 결과 단위.

## 6. 도메인 토큰 사전

화면군 전반에서 같은 의미는 같은 표기로 통일:

### 런닝 기록
- `{거리}` — km 단위 (`5.2 km`)
- `{시간}` — 분/초 (`28분 40초`)
- `{페이스}` — /km (`05:32 /km`)
- `{날짜}` — `YYYY-MM-DD`
- `{횟수}` — 회
- `{연속}` — 일

### 캐릭터
- `{캐릭터 이름}` — 부화 시 사용자가 지정, 변경 불가
- `{레벨}`, `{누적 EXP}`, 성장 단계(유아/유년/초기체/중기체/완전체) — **내부 데이터, 화면 노출 금지**
- `{archetype}`, `{fantasy_modifier}`, `{signature_marks}`, `{lore_one_liner}` — 내부 시드 (화면 노출 금지)

### 누적 / 진행
- `{누적 거리}` — 평생 누적 km

## 7. 권한·로그인 상태 가정

- **O1·O2 외 모든 화면**: 로그인 필수
- **M1 상태 A (알)**: 가입 직후 ~ 누적 10km 미만
- **M1 상태 B (캐릭터)**: 부화 완료 후
