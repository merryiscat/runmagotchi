E4 · 사이드 노트

의도

  • 완전체 캐릭터는 stage에서 사라지지 않음. 새 알·새 캐릭터와 함께 stage에서 공존·자유 이동.
  • ① 완성 축하: Lv.50 도달 시 M1 진입에서 자동 발동. 빛·파티클로 완전체 강조.
  • ② M1 복귀: 축하 종료 후 panel에 "새 알" 버튼 등장. 사용자가 원할 때 누름 — 강제 아님. 완전체만으로 계속 쓸 수 있음.
  • ③ 새 알 등장: "새 알" 버튼 누르면 새 알 생성(사주 시드 재사용, 새 DNA) + stage에 추가. 완전체와 새 알이 함께 돌아다님. 새 알의 누적 거리 0km부터 새 사이클.
  • "새 알" 버튼은 활성 알/캐릭터가 없을 때만 노출. 이미 성장 중인 캐릭터가 있으면 숨김.
  • EXP·부화·진화는 항상 최신 알/캐릭터 기준. 완전체는 stage 장식으로만 존재.

대안

  • 자동 가챠 (Lv.50 즉시 새 알 부여) — 쉬어가기 불가, 강제 사이클.
  • O2 재방문 (알 3개 중 선택) — 첫 경험 반복, 2회차 특별감 부족.
  • 명예의 전당 수납 후 새 알 — 캐릭터가 사라지면 아쉬움. 공존이 더 자연스러움.

미정

  • stage에 캐릭터 N마리 공존 시 시각 밀도 — 완전체 3마리 + 알 1개면 복잡할 수 있음. 캐릭터 수 상한?
  • 완전체 캐릭터 탭 시 상호작용 — 이름·정보 표시? 아무 반응 없음?
  • 런닝 스탯 귀속 — 업로드 EXP는 새 알/캐릭터에만? 완전체에도 뭔가 반영?
  • 새 알 생성 시 DNA 차별화 — 같은 생년월일인데 다른 결과. 시드에 회차 번호 추가?
  • "새 알" 버튼 위치 — panel 내 업로드 아래? 별도 섹션?
  • 완전체만 있는 상태(새 알 없이)에서 업로드 시 — EXP 무시? 업로드 차단? 칭호만 부여?
